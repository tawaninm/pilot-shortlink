## 2. Flow หลัก

**สร้างลิงก์ (happy):** วาง URL → (ใส่ alias ถ้าต้องการ) → กด "ย่อลิงก์" → ปุ่มเป็น "กำลังย่อ..." และกดไม่ได้ → แถวใหม่ขึ้นบนสุด พร้อมข้อความ "สร้างลิงก์แล้ว" ผ่าน `aria-live` และปุ่มคัดลอกได้ focus → ฟอร์มว่าง พร้อมสร้างลิงก์ถัดไป

**ดูสถิติ (happy):** คลิกแถว → แถวกาง (150ms) แสดง: คลิกรวม, กราฟรายวัน 30 วัน, referrer 10 อันดับรวมกลุ่ม "ไม่ทราบที่มา" → คลิกอีกครั้งหรือกด Esc เพื่อปิด
