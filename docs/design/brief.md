# Design Brief: pilot-shortlink

วันที่: 2026-11-17 | ขั้น: `uxui-workflow` 1 (ขั้น 2 ของ `web-build-workflow`) | สถานะ: ตะวันเลือกทิศทาง A 2026-11-17

- **Role / Context:** Claude ออกแบบแอปย่อลิงก์ที่มีหลายบัญชีและสถิติคลิก ผู้ใช้หลักคือตะวันที่แชร์ลิงก์ portfolio, CV และงานลง social ใช้ทั้งบนคอมและมือถือ (`docs/requirements.md`, `docs/research.md`)
- **Goal:** สร้างลิงก์ได้ในไม่เกิน 10 วินาทีจากหน้าแรก และรู้ภายใน 1 หน้าว่าลิงก์ไหนมีคนเปิดเท่าไรและมาจากไหน วัดด้วย e2e (จับเวลาการสร้างลิงก์), Lighthouse performance และ accessibility อย่างน้อย 90
- **Constraints:**
  - ต้องใช้: React + Vite + Tailwind 4 ผ่าน token ของโปรเจกต์ (theme bridge), shadcn เป็นฐาน component แต่ไม่ใช้หน้าตาค่าตั้งต้น, ภาษา UI ไทย, ไอคอน library เดียว
  - ห้าม: ทุกข้อใน `.agents/skills/uxui-workflow/references/slop.md` และเฉพาะงานนี้: พื้นครีม, ม่วงหรือ indigo, ฟอนต์ Inter/Geist/Roboto, การ์ดสถิติ 4 ใบเท่ากันแบบ Shlink, hero จัดกลางแบบหน้า marketing, ตัวเลขผู้ใช้หรือรีวิวปลอม, ภาพประกอบตกแต่ง
  - Tech: frontend เดียวใช้กับ backend A และ B ผ่าน OpenAPI
- **Reference:** (`docs/research/refs/`)
  - `01-dub-home.png`: เอาความเรียบของ nav และปุ่ม แต่ไม่เอา hero จัดกลาง
  - `02-bitly-home.png`: เอาแนวคิด "สร้างลิงก์ได้จากหน้าแรก" แต่ไม่เอาพื้นน้ำเงินเข้มและ banner ซ้อน
  - `03-shlink-home.png`: ตัวอย่างสิ่งที่ไม่เอา: การ์ดสถิติ 4 ใบเท่ากัน, ฟอร์มที่ช่องกรอกและปุ่มแยกห่างกัน
  - `04-dub-analytics.png`: เอากราฟเส้นที่อ่านง่ายและ tooltip ต่อจุด แต่ไม่เอากราฟหลายเส้นซ้อน (งานนี้มีตัวชี้วัดเดียวคือคลิก)
  - Kutt เปิดด้วย browser อัตโนมัติไม่ได้ (Cloudflare 403) จึงไม่มีภาพ
- **หน้าจอ:** สมัคร / เข้าสู่ระบบ, รายการลิงก์ + ฟอร์มสร้าง (หน้าหลัก), สถิติลิงก์, 404 ของลิงก์สั้น
- **Mode:** Exploration (3 ทิศทางด้านล่าง ต่างกันที่โครงสร้าง ไม่ใช่แค่สี)
- **Engine:** Thinking

## ทิศทาง A: บัญชีลิงก์ (ตาราง ข้อมูลแน่น)
- **พระเอก:** ช่องวาง URL แถวเดียวบนสุด ใต้ลงมาเป็นตารางลิงก์ คอลัมน์: ลิงก์สั้น, ปลายทาง, กราฟเส้นเล็ก 30 วัน, คลิก
- **โครง:** คอลัมน์เดียวกว้างสุด 1040px ชิดซ้าย แถวสูง 48px คลิกแถวแล้วสถิติกางลงใต้แถวนั้น ไม่เปลี่ยนหน้า
- **สี:** พื้น graphite อ่อน `oklch(0.97 0.004 250)` ตัวอักษร `oklch(0.22 0.01 250)` accent สีเขียวสัญญาณ `oklch(0.50 0.14 155)` (#00793d, contrast บนพื้น 5.06:1) ใช้กับลิงก์และกราฟเท่านั้น
- **ฟอนต์:** IBM Plex Sans Thai (UI), IBM Plex Mono (รหัสลิงก์และตัวเลข เลขทุกตัวกว้างเท่ากัน)
- **ความหนาแน่น / motion:** แน่น เห็นได้ 10-12 ลิงก์ต่อจอ, motion เฉพาะตอนกางแถว 150ms
- **เหมาะเมื่อ:** มีลิงก์เยอะและอยากเทียบหลายลิงก์พร้อมกัน **เสี่ยง:** บนมือถือตารางต้องแปลงเป็นแถวสองบรรทัด

## ทิศทาง B: สถิตินำ (สองแผง)
- **พระเอก:** ตัวเลขคลิกขนาดใหญ่และกราฟของลิงก์ที่เลือก
- **โครง:** desktop แบ่งสองแผง ซ้ายรายการลิงก์แคบ 320px (ปุ่ม "ลิงก์ใหม่" บนสุด) ขวารายละเอียดลิงก์ที่เลือก: ตัวเลขคลิกรวมใหญ่, กราฟรายวัน, แท่ง referrer แนวนอน มือถือเป็นสองหน้าซ้อนกัน
- **สี:** พื้น `oklch(0.985 0.002 90)` แผงซ้าย `oklch(0.95 0.006 60)` accent ส้มอำพัน `oklch(0.56 0.15 55)` (#b45600, contrast บนพื้น 4.71:1) ใช้กับตัวเลขหลักและแท่งกราฟ
- **ฟอนต์:** Anuphan (หัวข้อและตัวเลขใหญ่), Sarabun (เนื้อหา)
- **ความหนาแน่น / motion:** โปร่ง ตัวเลขหลักขนาด 56px, กราฟวาดเส้นครั้งเดียวตอนเปลี่ยนลิงก์ 300ms ปิดเมื่อ `prefers-reduced-motion`
- **เหมาะเมื่อ:** สนใจว่าลิงก์เดียวไปได้ดีแค่ไหน **เสี่ยง:** สร้างลิงก์ใหม่ต้องกดเพิ่ม 1 ครั้ง

## ทิศทาง C: พกพา (มือถือก่อน)
- **พระเอก:** แถบ "วาง URL แล้วย่อ" ติดล่างจอในระยะนิ้วโป้ง กดแล้วลิงก์สั้นถูกคัดลอกทันทีพร้อมปุ่มแชร์ของระบบ
- **โครง:** มือถือก่อน รายการลิงก์เป็นแถวเต็มความกว้าง ซ้ายเป็นลิงก์สั้นตัวใหญ่ ขวาเป็นจำนวนคลิก แตะแถวเปิด sheet สถิติจากล่าง desktop ใช้โครงเดียวกันกว้างสุด 640px
- **สี:** พื้นเข้ม `oklch(0.2 0.015 230)` (มีโหมดสว่างครบ) accent ฟ้าน้ำทะเล `oklch(0.72 0.12 200)` (#14bbc2, contrast บนพื้นเข้ม 7.69:1) สีสถานะสำเร็จแยกจาก accent
- **ฟอนต์:** Noto Sans Thai Looped (UI, หัวกลมอ่านง่ายบนจอเล็ก), JetBrains Mono (รหัสลิงก์)
- **ความหนาแน่น / motion:** ปุ่มและแถวสูงอย่างน้อย 48px, sheet เลื่อนขึ้น 200ms, มีสั่นเบาตอนคัดลอกสำเร็จบนมือถือที่รองรับ
- **เหมาะเมื่อ:** ส่วนใหญ่ย่อลิงก์จากมือถือแล้วแชร์ต่อทันที **เสี่ยง:** ดูสถิติหลายลิงก์พร้อมกันยากที่สุดในสามแบบ

ค่า accent ของ A และ B ลดความสว่างลงหลังวัดด้วย `ds-check contrast` (ค่าแรก #009351 ได้ 3.63:1 และ #e1791b ได้ 2.89:1 ไม่ผ่าน 4.5:1)

ทุกทิศทางต้องมี state ตาม `rules.md` (empty, loading, error, alias ซ้ำ, rate limit, ไม่มีสิทธิ์), contrast ผ่านสคริปต์ `ds-check` และกลุ่ม "ไม่ทราบที่มา" ในสถิติ
