# Page: ยืนยัน email, ลืมรหัสผ่าน, ตั้งรหัสใหม่ และ QR (2026-11-19, plan `pilot-addons`)

ใช้ layout, components และ tokens เดิมของ `auth.md` และ `links.md` ทั้งหมด ไม่เพิ่มสีหรือ component ใหม่ ข้อความในตารางด้านล่างคือข้อความจริงที่ e2e (`e2e/tests/addons.spec.ts`) หาด้วย role และชื่อ เปลี่ยนข้อความต้องแก้เทสต์พร้อมกัน

## แถบเตือนยังไม่ยืนยัน (หน้ารายการลิงก์)
- แสดงเมื่อ `GET /api/me` ได้ `emailVerified: false` อยู่เหนือฟอร์มสร้างลิงก์ `role="status"`
- ข้อความ: "ยืนยันอีเมลก่อนสร้างลิงก์ เราส่งลิงก์ไปที่ <email> แล้ว"
- ปุ่ม secondary "ส่งอีเมลยืนยันอีกครั้ง" กดแล้วข้อความเปลี่ยนเป็น "ส่งแล้ว ตรวจกล่องจดหมายของ <email>" ถ้าได้ 429 แสดง "ขอส่งบ่อยเกินไป ลองใหม่ใน <n> นาที"
- ฟอร์มสร้างลิงก์ยังแสดง แต่ปุ่ม "ย่อลิงก์" กดไม่ได้ (`disabled`) และมี `aria-describedby` ชี้ไปที่แถบเตือน

## หน้า `/verify-email?token=`
- ไม่ยืนยันทันทีตอนเปิดหน้า (ตัวสแกนลิงก์ในกล่องจดหมายบางตัวรัน JavaScript) ต้องกดปุ่ม primary "ยืนยันอีเมล" ซึ่งส่ง POST
- สำเร็จ: หัวข้อ "ยืนยันอีเมลแล้ว" และลิงก์ "ไปที่ลิงก์ของฉัน" (ไป `/`)
- token ใช้ไม่ได้: `role="alert"` "ลิงก์นี้ใช้ไม่ได้แล้ว อาจหมดอายุหรือถูกใช้ไปแล้ว" และลิงก์ "ไปที่ลิงก์ของฉัน" (ถ้า login อยู่จะเห็นปุ่มส่งใหม่ในแถบเตือน)
- ไม่มี token หรือรูปแบบผิด: ข้อความ alert เดียวกัน ไม่เรียก API

## หน้าเข้าสู่ระบบ
- เพิ่มลิงก์ "ลืมรหัสผ่าน" ใต้ช่องรหัสผ่าน ไป `/forgot-password` พร้อม email ที่กรอกไว้

## หน้า `/forgot-password`
- หัวข้อ "ลืมรหัสผ่าน", label "email", ปุ่ม primary "ส่งลิงก์ตั้งรหัสใหม่"
- ส่งแล้ว (204): `role="status"` "ถ้ามีบัญชีของ <email> เราส่งลิงก์ไปแล้ว ลิงก์ใช้ได้ 30 นาที" ข้อความเดียวกันทุกกรณี
- 429: "ขอลิงก์บ่อยเกินไป ลองใหม่ใน <n> นาที"

## หน้า `/reset-password?token=`
- หัวข้อ "ตั้งรหัสผ่านใหม่", label "รหัสผ่านใหม่" (`autocomplete="new-password"`) พร้อมเงื่อนไข "อย่างน้อย 10 ตัว" และปุ่มแสดงรหัสแบบเดียวกับหน้าสมัคร, ปุ่ม primary "ตั้งรหัสผ่านใหม่"
- สำเร็จ: ไป `/login` พร้อม `role="status"` "ตั้งรหัสผ่านใหม่แล้ว เข้าสู่ระบบด้วยรหัสใหม่"
- 422 `weak_password`: error ใต้ช่องแบบเดียวกับหน้าสมัคร
- 400 `token_invalid`: `role="alert"` "ลิงก์นี้ใช้ไม่ได้แล้ว อาจหมดอายุหรือถูกใช้ไปแล้ว" และลิงก์ "ขอลิงก์ใหม่" ไป `/forgot-password`

## ปุ่ม QR (แถวลิงก์ในหน้ารายการ)
- ปุ่ม icon ข้างปุ่มคัดลอก `aria-label="ดาวน์โหลด QR ของ /<code>"` ขนาดกดได้อย่างน้อย 44px เหมือนปุ่มอื่นในแถว
- กดแล้วดาวน์โหลด `<code>.svg` ที่เข้ารหัส `<origin ของหน้าเว็บ>/<code>` สร้างในเบราว์เซอร์ด้วย `qrcode` (`toString(url, { type: "svg", margin: 2 })`) สีดำบนพื้นขาวเสมอ ไม่ตามธีม เพราะแอปสแกนบางตัวอ่าน QR สีกลับด้านไม่ได้
- โหลด `qrcode` แบบ dynamic `import()` ตอนกดครั้งแรก ไม่เพิ่มขนาด bundle หน้าแรก

## Route ฝั่ง backend
`/verify-email`, `/forgot-password`, `/reset-password` ต้องเสิร์ฟ `index.html` เหมือน `/login` ทั้ง A และ B และเป็นคำสงวนของ alias แล้ว (requirements ข้อ 4)
