# Page: เข้าสู่ระบบ และ สมัคร

## Purpose
เข้าใช้งานด้วย email และรหัสผ่าน (สองหน้าใช้โครงเดียวกัน)

## Layout
คอลัมน์เดียวกว้างสุด 400px จัดชิดซ้ายภายในกล่องที่อยู่กลางจอ (หัวข้อสั้นเป็นข้อยกเว้นเดียวที่จัดกลางได้ตาม `rules.md`)
1. ชื่อแอป แล้วหัวข้อ "เข้าสู่ระบบ" หรือ "สร้างบัญชี" ห่าง `space-6`
2. label + ช่อง email (`autocomplete="email"`), label + ช่องรหัสผ่าน (`autocomplete="current-password"` หรือ `new-password`) พร้อมปุ่มแสดงรหัส ห่างกัน `space-4`
3. หน้าสมัคร: เงื่อนไข "อย่างน้อย 10 ตัว" ใต้ช่องรหัสตั้งแต่แรก
4. ปุ่ม primary เต็มความกว้าง ห่าง `space-6`
5. ลิงก์สลับไปอีกหน้า ห่าง `space-4`

## Components
`AuthForm` ปุ่ม primary 1 ปุ่ม ("เข้าสู่ระบบ" หรือ "สร้างบัญชี")

## States
idle, กำลังส่ง (ปุ่ม "กำลังเข้าสู่ระบบ..." กดไม่ได้), รหัสผิด, ล็อกชั่วคราว, email ซ้ำ (หน้าสมัคร), session หมดอายุ (ข้อความบนหัวฟอร์ม) ตาม `docs/design/flows.md`

## Responsive
mobile: เต็มความกว้างลบ `space-4` สองข้าง
desktop: กล่องกว้างสุด 400px อยู่กลางจอแนวนอน
